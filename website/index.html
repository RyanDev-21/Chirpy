How to install

Chirpy isn't on Google Play yet, so Android asks you to confirm the install.

  1. Tap Download above and open the file when it's done.
  2. If Android says installing unknown apps isn't allowed, tap Settings and turn on Allow from this source for your browser, then go back.
  3. Tap Install. If Play Protect warns that it doesn't recognise the app, tap More details → Install anyway.
  4. Open Chirpy and sign up with your email or Google.

Only download Chirpy from this page. To check the file wasn't changed, its SHA-256 checksum must match the one shown above. Chirpy tells you when a new version is out.
