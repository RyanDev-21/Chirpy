Install

Chirpy isn't on Google Play yet, so Android asks you to confirm the install. That's normal for apps from a website.

  1. Download. Tap Download for Android and open the file.
  2. Allow this source. If Android blocks unknown apps, tap Settings and turn on Allow from this source for your browser.
  3. Install. If Play Protect doesn't recognise the app, tap More details → Install anyway.
  4. Sign up with your email or with Google.

Only download Chirpy from this page. Compare the SHA-256 checksum under the button to check the file wasn't changed.
